# Maintainers

## Description rewrite before sindresorhus submission

Every entry description in `README.md` is a factual draft written for scaffolding. Before submitting this list to [sindresorhus/awesome](https://github.com/sindresorhus/awesome), a human on the team must rewrite each description. Fully AI-generated list content is rejected by sindresorhus/awesome and by awesome-selfhosted.

Suggested process:

1. Freeze the entry set.
2. Split categories among maintainers.
3. Rewrite each one-sentence description in a human voice.
4. Run `npx awesome-lint` and the link checker.
5. Wait until the repo has been public for at least 30 days, then open the Awesome PR.
